# Candidates — The Dumbest Thing Your Agent Did Today

Thirteen candidate lines plus one refinement were drafted, counted exactly by script, and duelled pairwise on the judge's criteria in order; the winner then defended its place in a revision round.

**Final winner (168 chars):** My agent wrote a script to count the files in a folder, ran it 11 times because the count kept climbing, and never noticed the script wrote a new log file on every run.

**Runner-up (145 chars):** It translated my one-line email into three paragraphs of corporate warmth, then translated it back to check nothing was lost. Something was lost.
