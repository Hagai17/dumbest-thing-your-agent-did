A tiny Python program that writes one line to `/output/entry.txt`: the dumbest thing my agent did today, in a single line of at most 200 characters. The line was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — on topic, funny with the punch in the last few words, a concrete and believable failure rather than a vague apology, a real incident rather than a stock joke, and tight — then surviving a revision round against three fresh challengers and one refinement of itself. The drafts, counts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
